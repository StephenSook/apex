## Dockerized harness `eval/Dockerfile`

Slim `python:3.10-slim` base + numpy + structlog. The V2 layer
(torch + cvxpylayers) is commented in the Dockerfile by default so
the bench image is pullable on small free-tier hosts; uncomment for
hosts that can install ~3.5 GB of ML deps. Bench gracefully degrades
on V2 absence: the `track_apex_v2` row falls back to `"skipped: <reason>"`
status rather than crashing.

Build + run:

```bash
docker build -t apex-bench:0.0.1-preview -f eval/Dockerfile .
docker run --rm \
  -v "$(pwd)/fixtures:/srv/fixtures:ro" \
  -v "$(pwd)/apex-bench/out:/srv/out" \
  apex-bench:0.0.1-preview
```
